# ELF OTC bot

## Запуск

Требуется Python 3.9 или новее.

1. Создайте нового бота через BotFather и установите зависимости:

   ```sh
   python3 -m pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и задайте токен бота. ID администратора уже указан в шаблоне. Можно также задать эти значения через переменные окружения:

   ```sh
   export TELEGRAM_BOT_TOKEN='токен-от-BotFather'
   export BOT_ADMIN_IDS='123456789'
   ```

   Для нескольких администраторов укажите ID через запятую.

   Файл `.env` исключён из архива и Git, чтобы токен не попал в публичный код.

3. Запустите бота из этой папки:

   ```sh
   python3 otc.py
   ```

Состояние пользователей, балансов и сделок сохраняется в `state.json` рядом с программой. Файл содержит пользовательские и платёжные данные: ограничьте к нему доступ и делайте резервные копии.

Переводы TON и RUB подтверждаются администратором вручную. Администратор должен заранее открыть бота через `/start`, чтобы получать запросы на проверку. После оплаты продавцу показывается получатель подарка `@otcmanagerr`. Оплата через Telegram Stars не интегрирована и отключена.
