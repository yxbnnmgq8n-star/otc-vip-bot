OTC VIP — версия для BotHost

Установка:
1. Загрузите otc.py, otc.jpg и requirements.txt в одну папку проекта.
2. Установите зависимости из requirements.txt.
3. В BotHost -> Environment Variables добавьте:
   BOT_TOKEN = НОВЫЙ токен, созданный через @BotFather
   ADMIN_ID = 6308550657
4. Команда запуска: python otc.py
5. Убедитесь, что с этим токеном не запущен второй экземпляр бота.

Поддержка: https://t.me/otcmanagerr

ВАЖНО:
- Токен, опубликованный в чате, следует немедленно отозвать в @BotFather.
- Новый токен не вставляйте в исходный код и никому не отправляйте.
- SQLite-файл otc_vip.sqlite3 должен сохраняться между перезапусками.
- Эта версия фиксирует договорённости и подтверждения участников.
  Она не принимает платежи, не хранит деньги, не подтверждает переводы
  и не направляет подарки/деньги администратору.
